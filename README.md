# Prasidha Jagtap — personal website

A simple one-page resume site. Plain HTML + CSS, no build step.

- `index.html` — the content (look for `[brackets]` and `TODO` comments to fill in)
- `style.css` — the look (light + dark mode, phone friendly, "Save as PDF" print style)

## Put it online for free (GitHub Pages)

1. Merge this branch into `main`.
2. On GitHub: **Settings → Pages → Build and deployment**.
3. Source: **Deploy from a branch** → Branch: `main` → Folder: `/ (root)` → **Save**.
4. After 1–2 minutes the site is live at:
   **https://prasidhajagtap.github.io/projectP001/**

Want the shorter URL `https://prasidhajagtap.github.io/`? Rename this repo to
`prasidhajagtap.github.io` (Settings → General → Repository name).
